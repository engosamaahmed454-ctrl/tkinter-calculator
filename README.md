# 🧮 Tkinter Calculator

A simple desktop calculator built with Python's built-in `tkinter` library — no external dependencies.

## Features

- Addition, subtraction, multiplication, division, modulo
- Decimal numbers
- Clear (`C`) and backspace (`⌫`)
- Dark-themed UI

## Run it

```bash
python calculator.py
```

Requires Python 3 (tkinter ships with most standard Python installs).

## Why I built this

One of my first Tkinter projects — a way to practice building a GUI with buttons, layout grids, and event-driven programming in Python.
